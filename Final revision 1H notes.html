A — Expansion

✦ Multiply each term in the bracket by ALL the other terms in the other bracket.

Example
(x + 5)(x − 6) = x² + 5x − 6x − 30 = x² − x − 30

F — Completing the Square
Case 1: No coefficient for x²
Example: x² − 10x + 40
  1. 1Write (x − b/2)² → (x − 10/2)² = (x − 5)²
  2. 2Add the last term beside the bracket → (x−5)² + 40
  3. 3Square the 2nd term in bracket and put it outside with −ve sign → (x−5)² + 40 − 25
  4. 4Simplify → (x − 5)² + 15
Case 2: Coefficient for x²
Example: 3x² − 12x + 7
  1. 1Take the coefficient as a common factor from first 2 terms only → 3(x² − 4x) + 7
  2. 2Do (x − b/2)² for what's inside the bracket → 3(x − 2)²
  3. 3Add last term beside the bracket → 3(x−2)² + 7
  4. 4Square the 2nd term in bracket, multiply by the number outside, then subtract → 3(x−2)² + 7 − 3×(2²)
  5. 5Simplify → 3(x − 2)² − 5

H — HCF and LCM

LCM

Take everything, and if something is common take the highest power.

HCF

Take only the common parts from both, but with the lowest power.

Example: A = 2³×3²×5×7, B = 2⁵×3×7²
HCF = 2³ × 3 × 7
LCM = 2⁵ × 3² × 5 × 7²
Example: HCF and LCM of (36, 120)
36 = 2² × 3² | 120 = 2³ × 3 × 5
HCF = 2² × 3 = 12
LCM = 2³ × 3² × 5 = 360
I — Simultaneous Equations
Type 1: 2 Linear Equations — 2 methods

Method 1: Elimination

Multiply one or both equations by a number to equate coefficients, then subtract.

3x + 4y = 16 ×2 → 6x + 8y = 20 ⎫
2x + 3y = 7 ×3 → 6x + 9y = 21 ⎭
subtract ↑ → −y = −1 → y = 1
sub y=1 back in → 6x + 8(1) = 20 → 6x = 12 → x = 2

Method 2: Substitution

Make x or y the subject in one equation, then substitute into the other.

① 3x + 4y = 10 → make x subject → x = −4y + 103
②
2x + 3y = 7
2 × −4y+103 + 3y = 7
→ −8y+203 + 3y = 7 → −8y + 20 + 9y = 21 → y = 1
sub y=1 in ① → x = −4(1)+103 = 63 → x = 2

Lines

Key Formulas
Line equationy = mx + c
Slope/Gradientm = y₂ − y₁x₂ − x₁
Distanced = √(y₂−y₁)² + (x₂−x₁)²
Midpoint= (x₁+x₂2 , y₁+y₂2)
Key Rules
  • 2 lines parallel → same slope (m₁ = m₂)
  • 2 lines perpendicular → slopes multiply to −1 (m₁ × m₂ = −1), so flip and negate (شقلب وقلب)
  • Line meets x-axis → put y = 0 and get x
  • Line meets y-axis → put x = 0 and get y
  • 2 lines intersect → equate them and solve
  • If equation is given as 2y + 3x = 5 → make y the subject: y = −32x + 52 ⚠️ Important!
Getting the Equation of a Line
Step 1: Get m (gradient)

Either use (y₂ − y₁)/(x₂ − x₁) if you have 2 points, or if there's a parallel/perpendicular line, use its slope (or flip and negate (شقلب وقلب) for perpendicular).

Step 2: Get c (y-intercept)

There is ALWAYS a point the line passes through — substitute that point into y = mx + c to get c.

Example: y = 2x + c, passes through (2, 3) → 3 = 2(2) + c → c = −1 → y = 2x − 1
📌Lines questions will ALWAYS be solved using slope, distance, or midpoint rules. Always sketch if shapes are given!

Probability

🚨 Don't Forget — AT LEAST

When the question says "AT LEAST", 95% of the time you use:

P(at least one) = 1 − P(none)

It's easier to find the probability it does NOT happen, then subtract from 1.

Example: A bag has 3 red and 7 blue balls. You pick 2. P(at least one red)?
Instead of: P(1 red) + P(2 red) — complicated!
Use: 1 − P(no red) = 1 − P(both blue)
P(both blue) = 710 × 69 = 4290 = 715
P(at least one red) = 1 − 715 = 815
Core Rules
TotalSum of all probabilities = 1
AND= × (multiply)
OR= + (add)
P(event)= what you wanttotal
💡 When solving, try to say all the possibilities with your mouth first, then write what you're saying.
Example
Bag has 5 red and 15 green balls (total = 20). Find P(one red AND one green).
P(red then green) OR P(green then red)
= P(R,G) + P(G,R)
= (520 × 1519) + (1520 × 519)

Histogram

⚠️ ALWAYS do this first!

Write the rule the SECOND you know it's a histogram question: Frequency Density = FrequencyClass Width

Key Definitions
Freq. Density= FrequencyClass Width
Frequency= number of (people, apples, cars…)
Class Width= width of the histogram bar you will draw
4 Types of Histogram Questions
Type 1 — No bars drawn at all
  1. 1Use the rule to get Frequency Density
  2. 2Draw histograms
Type 2 — Histograms drawn but no y-axis (2 cases)

Case 1

He gives you info about frequency of one of the bars → use rule to get freq. density, then scale y-axis accordingly.

Case 2

No info about freq. density → assume the axis. e.g. 1 big square = x and try to solve.

Type 3 — Full histogram with y-axis

He will ask about the frequency within a range. Example: calculate the number of people older than 30.

Type 4 — Partially drawn histogram
  1. 1Use one of the given frequencies to calculate the f.d of that bar, then scale the y-axis accordingly
  2. 2Use the rule to get the rest of the frequencies
  3. 3Draw missing histograms

📝 Steps:

  3. 3Set equal to 160 → solve for x
  4. 4Count ALL large squares across every bar × x = total students

Key Rule

✦ Always set up as: Old : increase or decrease : New — where Old is always 100

Old : change : New
→
100 : % : (100 ± %)
Always put 100 in the Old column. Cross multiply to find x.

Old decrease New 100 30 70 x 80

Standard Form Format
Forma × 10ⁿ   where   1 ≤ a < 10
Adding / Subtracting in Standard Form

✦ Make all numbers have the same power of 10, then add/subtract the numbers in front normally.

3×10⁵ + 2×10³
Make both ×10⁵ → 3×10⁵ + 0.02×10⁵
Add the coefficients → (3 + 0.02) × 10⁵ = 3.02 × 10⁵

Key Method

✦ Use cross multiplication to convert between currencies. Always go step by step if there's no direct rate.

Example
Convert 50 pounds to yen   (1 euro = 120 yen,   1 pound = 1.2 euros)
Step 1: pounds → euros
